# 术语表

## UVP 工具术语

| 术语 | 定义 |
|------|------|
| ADR | Architecture Decision Record，架构决策记录 |
| Feature Ledger | 特性账本，管理特性完整生命周期的文档体系 |
| spec.md | 特性规格说明（合同）：做什么 + 验收标准 + 接口契约 + 约束 + 人工决策结论 |
| changelog.md | 特性变更日志，记录每次代码变更 |
| verification.md | 特性验证记录，记录代码验证结果；复杂任务引用实验结果路径完成闭环 |
| context.md | 交给 AI 的既定事实上下文，由 Distill 步骤维护，关闭时填写 |
| plan.md | 特性实施计划（可选），AI 规划步骤，简单特性可指向 ADR Actions |
| PROJECT_STATE.md | 项目当前状态，AI 的首要参考文档 |
| AI_CONTEXT.md | AI 编程工具的强制规则文件 |
| Feature Registry | 特性注册表，记录所有特性的状态和元数据 |
| ADR Registry | 决策注册表，记录所有 ADR 的状态和索引 |
